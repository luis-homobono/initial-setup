# Initial Setup

This repo contain the first configurations and installations in my system.

The repo will be contain the next scripts:
- Utilities with functions or alias more used in my terminal.
- Tools used in development.
- List of software used daily for me and instructions for its installations.

## Details for platforms
This scripts will be used in systems based on Unix in special system used for me.

## Instalation
You can install this utils and software with the next commands:

```
git clone -b master --single-branch https://github.com/luis-homobono/initial-setup.git ~/.local/share/initial-setup >/dev/null

cd ~/.local/share/lekub

source ~/.local/share/initial-setup/install.sh
```
